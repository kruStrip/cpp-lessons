# C++: практикум

Работы по C++: структуры данных, ООП, шаблоны, сокеты и приложения на WinAPI.

**Стек:** C++ · WinAPI · сокеты

## Что внутри

- `linked-list`, `doubly-linked-list`, `int-set` — односвязный и двусвязный списки, множество на бинарном дереве
- `templates`, `templates-2`, `templates-3` — шаблоны классов и функций
- `polymorphism`, `book-class`, `shop`, `static-methods` — ООП: наследование, классы, статические методы
- `exceptions` — обработка исключений
- `maze`, `snake`, `tic-tac-toe`, `minesweeper` — игры
- `paint`, `winapi-oop` — оконные приложения на WinAPI
- `socket-server`, `socket-client` — обмен данными по TCP
- `multithreading`, `multithreading-task` — потоки
- `macros`, `encryption`, `command-line-args`, `substring-operator`, `substring-usage`, `students` — отдельные задания

## Запуск

Открыть `cpp-lessons.sln` в Visual Studio и собрать нужный проект.
